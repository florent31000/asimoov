# Contributing

ASIMOOV is pre-alpha and not yet accepting external contributions in a
structured way. This file is a stub; a real contribution guide (coding
style, how to add a body adapter, how to submit a persona) lands with the
public launch.

For now:

- Open an issue before a large pull request.
- Match the existing code style (`ruff check .` must pass).
- New code and docs in English.
- `pytest` must pass before submitting.
