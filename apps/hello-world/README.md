# apps/hello-world

Minimal example app (`asimoov-app.yaml` + entry point) demonstrating the
`app.v1` manifest with no permissions and no tools: a template for new apps.

Not owned by WS0. See `plan.md` section 4.3 (App manifest) for the schema
this app must validate against (`asimoov/contracts/schemas/app.v1.json`).
