# bodies/avatar (WS6)

Virtual body: eyes-only, no motion, no camera by default. Backs the
`asimoov run robots/avatar` demo. Implements `asimoov.contracts.body.Body`.

Owned by WS6 (bundled with `faces/`). See `plan.md` section 4.12, row WS6.
The `robots/avatar/` example robot (owned by WS0) targets this body.
